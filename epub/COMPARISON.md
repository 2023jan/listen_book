# 旧 TXT 项目与 EPUB 项目的对比

对比来源：旧仓库的 `tools/easyvoice_batch.ps1`、`tools/split_novel.ps1`，以及本次 EPUB 项目的首版代码。

| 方面 | 旧项目 | EPUB 首版 | 本次改进 |
|---|---|---|---|
| 输入 | UTF-8 TXT，以特定章节标题格式切分 | EPUB spine 文档 | 保留 EPUB 路线及明确的章节编号核对 |
| 语音 | 本机 EasyVoice Docker 服务 | 直接调用免费在线 Edge TTS | 保留直接在线，无需 Docker/本地模型 |
| 并发 | 文件级 1～3 路，默认 3 | 全部串行 | 同章片段固定 worker 池，1～3 路，默认 3 |
| 重试 | 失败文件清单、RetryFailed | 片段自动重试、哈希缓存 | 结合两者；失败章继续执行，支持仅重试失败章 |
| 跳过 | 同名音频存在即跳过 | 成功片段缓存，但整章仍合并 | 通过内容/声音键和最终音频哈希验证后跳过 |
| 状态 | JSON 运行状态、CSV 清单 | 仅完成章的 report.json | 每段状态原子保存、失败章清单、每章收据 |
| 结果校验 | HTTP 成功后保存，未做音频解码校验 | ffprobe + 最终完整解码 | 保留音频校验；失败不替换已有成品 |
| 多进程冲突 | 文档建议不同输出目录 | 未处理 | 同目录操作系统锁，崩溃后可重新运行 |

没有照搬旧项目的“默认约两万字一块”：当前客户端分段约 1200 字，更利于失败时局部重试。最终仍输出整章 MP3，文件数量不会因语音请求片段增多。

旧项目分割脚本会清空输出目录；此次不引入此行为。TXT、EasyVoice 工具继续保留，EPUB 模块独立新增，不改动旧流程和已有音频。

第一版仍按 EPUB HTML 文档边界分章；不宣称支持任意目录锚点或跨文档章节自动合并。PDF/OCR 留待后续。
